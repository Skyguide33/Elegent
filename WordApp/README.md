# 英语背单词（控制台版）

一个简单的 C++ 控制台背单词程序，支持：

- 添加/更新单词（若已存在会提示并可替换中文释义）
- 查找单词（英文精确查找；中文子串检索并按字典序输出）
- 默写（按重点/一般 + 最近背诵时间 + 艾宾浩斯计划优先级抽取）
- 文件持久化（退出时保存，下次打开自动读取）

## 编译与运行（Windows）

在 `WordApp/` 目录下：

```bash
g++ -std=c++17 -O2 -pipe -static -s -o wordapp.exe main.cpp
.\wordapp.exe
```

程序数据文件为同目录下的 `wordbook.db`（TSV + 转义），可直接备份。
